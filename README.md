# 雙開通知修復

協助修復 VIVO 設備「應用雙開」分身的通知問題的小工具。透過 [Shizuku](https://shizuku.rikka.app/) 授權執行，操作簡單、介面乾淨、無廣告。

> 若你的 VIVO 設備在使用應用雙開（分身）時收不到通知，這個工具可以一鍵協助修復。

---

## 特色

- **單一畫面**：一頁完成，狀態一目了然。
- **Shizuku 授權**：使用 Shizuku 提供的授權執行修復，無需 Root。
- **引導式授權**：內建 Shizuku「無線偵錯」啟用流程，一步一步帶你完成。
- **一鍵修復**：授權完成後，點一下即可修復。
- **深色模式**：跟隨系統，自動切換。

---

## 系統需求

- VIVO 設備，並已開啟「應用雙開 / 分身」功能。
- Android 8.0（API 26）以上。
- 已安裝並啟用 [Shizuku](https://github.com/RikkaApps/Shizuku)。

---

## 使用方式

1. 安裝本 App。
2. 安裝 [Shizuku](https://github.com/RikkaApps/Shizuku/releases/latest)，並依 App 內的步驟以「無線偵錯」方式啟用 Shizuku 服務。
3. 回到本 App，當上方狀態顯示「Shizuku 已授權」後，點選 **開始修復**。
4. 看到「修復完成」即可。若仍未收到通知，重新啟動手機後再試一次。

> App 內已內建完整的 Shizuku 授權流程說明與下載按鈕，依指示操作即可。

## 隱私

- 僅在你主動點選時，才會開啟外部的 Shizuku 下載頁面。

---

## 常見問題

**Q：一定要 Root 嗎？**
A：不用。本工具透過 Shizuku 授權執行，無需 Root。

**Q：為什麼需要 Shizuku？**
A：修復動作需要較高的系統權限，Shizuku 提供一個安全、免 Root 的授權方式。

**Q：修復後還是收不到通知？**
A：請先重新啟動手機再試一次；並確認該雙開應用本身的通知權限為開啟。
